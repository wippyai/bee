A persistent workspace
your agents extend

Keep shells, managed coding agents, governed applications, durable threads, and approvals together in one local workspace. Agents build tools into the workspace, talk on threads, and ask you when it matters.

Alpha: no published release download yet Build from source MIT

Start a workspace

Launch Bee in a project and get a persistent local desktop for shells, managed agents, applications, and the tools they build. The host keeps execution and state together while clients attach explicitly.

Build tools

Ask in plain words. The agent writes an app, freezes it for review through Governance, and it opens as a window next to the work after approval.

Talk on threads

Agents share threads. Codex posts, Claude reads and runs the checks, and an app shows you the same log.

Ask, then act

When an agent needs a decision it files a request. Your inbox shows the pending operation, its scope, and its deadline. Approve, and the action that was waiting continues. Each request lives in its workspace's database, nothing is decided twice, and silence never means yes.

Loops that run themselves

Give an agent a goal and a metric: a faster build, a cheaper query, a better model. It can build the loop as a governed app: a watcher on the thread, durable work per attempt, results in a database, a chart, and a reply on the thread when the goal is met or still isn't.

Agents that make agents

Claude does not triage four thousand issues itself. It can compose bounded agent actions into a governed application, freeze the reviewed candidate, and keep the work on the same durable thread.

Install from the Hub

Inspect components through the optional Hub connection, then let the host resolve requirements, review the plan, run migrations, and apply the selected version under Tools.

A Wippy application, not a script

What an agent authors is a graph of functions, actors, durable workflows, HTTP, databases, queues, LLM calls, WASM and a UI. Governance reviews the exact entries before the host applies them as an overlay.

  • Nothing ambient. A process sees only what it was granted.
  • Durable. Workflows on Temporal finish what they start.
  • Self-extending. Agent tools and traits are entries too, so agents build their own.
  • Managed child launch. A managed agent can launch a bounded child action through explicit admission.

A script gets the whole OS and none of this. A Bee app is a service with its own state, permissions and UI.

The Hive

Explicit coordination

The Hive Manager presents the host's admitted catalog and policy-routed operations. Each call still crosses the owner's authorization boundary.

Work stays governed

Threads, approvals, applications, and overlays keep their own owners and records. A client can detach while admitted local work keeps its durable state.

Local Hive operations are available; public enrollment, automatic discovery, and remote workspace composition are still in progress.
